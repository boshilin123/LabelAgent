# LR-Agent 手工逐步启动与调试

这份流程用于学习和定位问题。日常使用可以执行 `scripts\start-lr-agent.ps1`，调试时建议按下面顺序逐层确认。

## 0. 打开 Docker Desktop

等待 Docker Desktop 显示 Engine 已启动，然后打开 PowerShell：

```powershell
docker version
```

Server 部分能正常输出才继续。

## 1. 启动后端基础服务

```powershell
cd D:\Study\LR-Agent\LR-Agent-backend\docker
docker compose up -d
docker compose ps
```

应看到 `lr-agent-api`、`lr-agent-postgres`、`lr-agent-redis`、`lr-agent-minio`。PostgreSQL 和 Redis 应为 `healthy`。

验证 API：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

查看后端实时日志：

```powershell
docker compose logs -f api
```

按 `Ctrl+C` 只退出日志查看，不会停止容器。

## 2. 单独验证 local-agent

Electron 正常启动时会自动拉起 local-agent，这一步只用于独立调试。

```powershell
cd D:\Study\LR-Agent\LR-Agent\vendor\local-agent
$env:LR_AGENT_LOCAL_PORT = '8765'
$env:LR_AGENT_LOCAL_TOKEN = 'local-debug-only'
D:\Study\LR-Agent\.venvs\lr-agent-local\Scripts\python.exe local_main.py
```

另开一个 PowerShell 验证：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/health
```

验证后在 local-agent 窗口按 `Ctrl+C`，避免和 Electron 自动启动的实例重复。

## 3. 单独验证 CPU 推理服务

Electron 会按需启动 inference，这一步同样只用于独立调试。

```powershell
cd D:\Study\LR-Agent\LR-Agent\vendor\inference
$env:YOLO_CONFIG_DIR = 'D:\Study\LR-Agent\.venvs\.runtime\ultralytics'
$env:MPLCONFIGDIR = 'D:\Study\LR-Agent\.venvs\.runtime\matplotlib'
'{"cmd":"ping"}' | D:\Study\LR-Agent\.venvs\lr-agent-inference\Scripts\python.exe server.py
```

输出中应包含：

- `pythonOk: true`
- `torchVersion: 2.5.1+cpu`
- `cudaAvailable: false`
- `ultralytics/sam2/mediapipe/faceAlignment/opencv: true`

## 4. 启动 Electron 桌面端

确认第 2、3 步的独立测试进程已经停止，然后执行：

```powershell
cd D:\Study\LR-Agent\LR-Agent
$env:LR_AGENT_LOCAL_PYTHON = 'D:\Study\LR-Agent\.venvs\lr-agent-local\Scripts\python.exe'
$env:LR_AGENT_INFERENCE_PYTHON = 'D:\Study\LR-Agent\.venvs\lr-agent-inference\Scripts\python.exe'
$env:API_BASE_URL = 'http://localhost:8000/api/v1'
$env:ELECTRON_CACHE = 'D:\Study\LR-Agent\.venvs\.runtime\cache\electron'
$env:YOLO_CONFIG_DIR = 'D:\Study\LR-Agent\.venvs\.runtime\ultralytics'
$env:MPLCONFIGDIR = 'D:\Study\LR-Agent\.venvs\.runtime\matplotlib'
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
npm run dev
```

正常现象：

- webpack renderer 监听 `1212`；
- Electron 出现 LR-Agent 窗口；
- MCP 服务日志显示一个 `127.0.0.1` 随机空闲端口；
- local-agent 日志显示健康检查通过，并输出本次使用的随机空闲端口；
- 首次使用自动标注时出现 inference spawn 日志。

停止桌面端时，在该 PowerShell 中按 `Ctrl+C`。

## 5. 查看整体状态

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\Study\LR-Agent\scripts\status-lr-agent.ps1
```

## 6. 停止后端

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\Study\LR-Agent\scripts\stop-backend.ps1
```

该命令只停止容器并保留 PostgreSQL、Redis、MinIO 数据卷。

## 推荐的排错顺序

1. `docker compose ps`：基础服务是否健康。
2. 后端 `/health`：账号 API 是否可达。
3. local-agent `/health`：Agent 编排服务是否正常。
4. inference `ping`：Python 与模型依赖是否正常。
5. 最后检查 Electron/renderer：这样能快速判断问题在哪一层。
