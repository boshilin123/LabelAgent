## 教学与事实核对

- 采用参考飞书课程的编号、短段落、名词卡、业务问题、输入输出、流程、分步实验及回顾；章节依赖按本项目重新组织。
- 各章给出实际源码路径和符号。完整实验、源码节选与教学简化结构分开标注；练习脚本由读者按 PDF 自行新建，不依赖临时附件。
- 修正 Context 语义静态但数据模型未 frozen、X | None 不等于可省略、ToolRunner 业务分类不等于 Python 同异步等易错表述。
- 说明请求重建续跑不等于持久化图恢复；当前工厂未传 checkpointer/Store。完成 ID 和消息过滤不扩大为全局并发 exactly-once。
- 说明只读子代理的 focus_path 只是优先查阅提示，真正约束来自工具白名单和底层路径检查；工具重试白名单当前为空。
- 推理 JSON Lines 的 params 位于 model 内；bbox 实验解释中心、宽高、偏移及归一化。confidence 不写成实际准确率。
- 简历部分区分阅读、复现、亲自改造。没有真实简历文件，不虚构个人职责或提升比例；协作产物须由读者亲自运行和解释后形成贡献记录。
