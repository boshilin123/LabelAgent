## 实际处理的问题

1. Docker Hub 认证端点连接超时。
   - PostgreSQL、Redis 镜像重试后成功。
   - MinIO 改用 Quay 官方镜像。
   - API 的 Python 基础镜像改从 AWS Public ECR 获取。
2. npm 默认缓存目录无写权限。
   - 改用 `.venvs\.runtime\cache\npm`。
3. Electron 默认缓存目录无写权限。
   - 改用 `.venvs\.runtime\cache\electron`，并使用 npmmirror。
4. PyPI 官方源连接慢。
   - Python 依赖改用清华 PyPI 镜像，PyTorch CPU wheel 仍使用 PyTorch 官方源。
5. SAM2 的 GitHub clone 多次中断。
   - 改为下载官方源码 ZIP，并以 `--no-deps --no-build-isolation` 安装。
6. Ultralytics 和 Matplotlib 默认配置目录无写权限。
   - 固定为 `.venvs\.runtime\ultralytics` 与 `.venvs\.runtime\matplotlib`。
