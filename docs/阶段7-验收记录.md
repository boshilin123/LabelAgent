## 5. ⚠️ 重大缺陷与修复：旧路径被候选包的 `__init__` 拖垮（父代理独立发现）

### 5.1 缺陷

阶段 7 初版在 `local_chat_stream` 里于 **engine 判定之前**执行：

```python
from app.agent.langchain_runtime.entry import stream_engine_sse
```

**实测（baseline 环境，无 `langchain`）**：

```
ModuleNotFoundError: No module named 'langchain'
  File ".../langchain_runtime/__init__.py", line 46, in <module>
    from app.agent.langchain_runtime.middleware import (
  File ".../middleware.py", line 47, in <module>
    from langchain.agents.middleware import (
```

导入**子模块**会先执行包的 `__init__.py`，而该 `__init__` 会导入 `middleware`（需要 `langchain`）。原生产环境只装了 `langchain-core`/`langchain-openai`/`langchain-mcp-adapters`，**没有** `langchain`/`langgraph` ⇒ **legacy 路径的每一次 `/chat/stream` 请求都会 500**。这正是阶段 7 门槛「旧路径行为不得改变」所禁止的回归。

### 5.2 为什么常规测试结构抓不到（三层同时失效）

1. 候选测试在 baseline 环境被 `pytest.importorskip("langchain")` **整模块跳过**；
2. `tests/test_chat_stream_preparing.py` 是**直接调 `_stream_local_chat`**，不经过路由函数，故那条惰性 import 从未执行；
3. migration 环境有 `langchain`，stage7 的 30 个用例全绿。

**因此该缺陷只在「baseline 环境 + 走路由函数」时可见**——父代理在验收时手工构造了该组合才暴露。

### 5.3 修复

```python
engine = str(getattr(settings, "agent_engine", "legacy") or "legacy").strip().lower()
if engine != "candidate":
    return StreamingResponse(_stream_local_chat(body, settings), media_type="text/event-stream")
from app.agent.langchain_runtime.entry import stream_candidate_engine_sse
return StreamingResponse(stream_candidate_engine_sse(body, settings, is_cancelled=None), ...)
```

即**判定先于 import**：legacy 分支**完全不触碰候选包**（生产环境无 `langchain` 亦安全，且省掉每请求的 import 开销）；只有 `candidate` 才惰性 import。

### 5.4 新增回归（行为级，两个环境都会执行）

`tests/test_engine_switch_import_safety.py`（5 用例，**不 import 任何 langchain**）：

- 毒化 `sys.modules["app.agent.langchain_runtime"] = None` → legacy 路径仍必须产出 SSE 帧；
- legacy 调用后候选包**任何子模块都不得进入 `sys.modules`**；
- `AGENT_ENGINE=candidate` 且包不可用时**必须明确 `ImportError`**，不得静默回退；
- 默认值必须是 `legacy`；非法取值必须被 `Literal` 拒绝。

同时把执行者原有的**源码文本断言**（`test_old_module_does_not_import_candidate_package`）更新为「import 行必须在 `!= "candidate"` 判定之后」，并注明行为级回归在专门文件里。**教训已存项目记忆 `ins_a5f67435`**：只做源码文本断言抓不到这类运行时缺陷。
