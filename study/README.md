# LR-Agent 学习资料

面向“只懂最基本 Python、LangChain 从零开始”的学习者，重点是 Python 后端、LangChain 与 Agent，以及后续项目简历和面试。

按顺序阅读：

1. [第00章：学习前检查与讲解规范](LR-Agent_第00章_学习前检查与讲解规范.pdf)：范围、路线与简历证据。
2. [第01章：读懂Agent所需的Python基础](LR-Agent_第01章_读懂Agent所需的Python基础.pdf)：先补阅读源码会遇到的语法。
3. [第02章：LangChain模型消息与链入门](LR-Agent_第02章_LangChain模型消息与链入门.pdf)：先用完整离线实验建立框架直觉。
4. [第03章：工具调用与Agent核心循环](LR-Agent_第03章_工具调用与Agent核心循环.pdf)：工具 Schema、执行分类、官方循环和 Context/State，20 页。
5. [第04章：Middleware与业务约束](LR-Agent_第04章_Middleware与业务约束.pdf)：钩子、阶段、回合规划、预算及重试边界，20 页。
6. [第05章：FastAPI流式接口与请求续跑](LR-Agent_第05章_FastAPI流式接口与请求续跑.pdf)：请求校验、SSE、取消、工具 ID 与结果重建，21 页。
7. [第06章：MCP子代理与上下文记忆](LR-Agent_第06章_MCP子代理与上下文记忆.pdf)：发现适配、只读委派、上下文和记忆职责，21 页。
8. [第07章：模型适配与推理工具接入](LR-Agent_第07章_模型适配与推理工具接入.pdf)：主/辅助模型、视觉回退、坐标与推理协议，21 页。
9. [第08章：后端测试调试与证据](LR-Agent_第08章_后端测试调试与证据.pdf)：合同、失败注入、协议回归与评价边界，19 页。
10. [第09章：个人改造与简历面试复盘](LR-Agent_第09章_个人改造与简历面试复盘.pdf)：贡献记录、小改造、项目介绍与追问，19 页。

完整安排见 [学习准备与章节计划](../docs/学习准备与章节计划.md)。

本套基线为 2026-10-17 的 `d5dd009`。教材按当前源码核对；前期修正了少量历史注释，本轮另修复已复现的日志 EPIPE 异常，未改变 Agent 决策、推理和标注行为。正式 Agent 环境是 `.venvs/langchain-main`，当前默认内核配置值是 `candidate`。

## 命名与编写约定

- 文件采用 `LR-Agent_第01章_读懂Agent所需的Python基础.pdf` 等稳定命名，章节标题改动时同步更新目录。
- 每节按“问题场景 → 学习目标 → 名词解析 → 适用场景 → 流程 → 源码 → 实验 → 结果解释 → 练习”组织。
- 代码标明“完整教学实验 / 源码节选 / 教学简化示例”。完整实验包含导入、输入、运行命令、预期输出和解释。
- 项目源码与运行环境决定事实，课程提供讲法；课程版本和示例不直接覆盖本项目依赖。
- 新语法先给小例子再读生产符号，逐步解释数据怎样进入和返回；每章增加面试追问与个人证据记录。
- 简历区分阅读、复现、亲自改造；已有项目能力不自动成为本人开发经历，数字必须有真实记录。
- 本项目不引入 RAG。RAG 资料用于理解知识检索与工具执行的区别，以及学习教材如何组织问题和实验。
- 最终保留 PDF 与必要说明；样章代码由读者从 PDF 复制新建，不依赖临时附件脚本。

真实主流程引用 [2026-10-17 验收记录](../docs/2026-10-17本地主流程验收记录.md)。本轮新增实验与 13 项后端定向 pytest 均为离线验证，没有重新调用云模型或 YOLO；历史整套测试和两图验收单独标注。教材检查详见 [PDF 制作与验证记录](../docs/2026-10-17学习PDF制作与验证记录.md)，故障修复详见 [日志断管道记录](../docs/2026-10-17日志断管道修复记录.md)。
