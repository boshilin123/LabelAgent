# Agent 自学阶段规划

## 一、学习目标与执行原则

本项目以已经部署完成的 LR-Agent 作为可运行、可调试、可修改的 Agent 学习案例。按项目真实依赖和调用链组织学习章节，参考飞书文档的概念讲法、排版与实验组织。

2026-10-17 当前学习入口见 [学习准备与章节计划](学习准备与章节计划.md) 和 [study 目录](../study/README.md)。读者仅掌握最基本 Python，LangChain 从零开始；先补 Python 与模型/消息基础，再学习 Agent。本页保留历史阶段目标，章节顺序和学习范围以新入口为准；后文多 Agent/Review 设想不是当前必修项或已有能力。

每学习飞书文档中的一个知识点，都尽量完成下面四个动作：

1. 理解课程中的概念与原理；
2. 在 LR-Agent 中找到对应源码；
3. 完成一个可以独立验证的最小实验；
4. 将结论、问题和实验结果记录到中文学习文档，并提交到 LabelAgent 仓库。

学习期间遵循以下约定：

- 项目调用链决定章节顺序，飞书文档提供讲解方法和对应概念；
- 当前主修目录是 `LR-Agent/vendor/local-agent`；
- 不安排 Electron/React 或桌面内部实现学习；外部调用方只用于解释后端请求、工具结果和确认协议；
- `LR-Agent-backend` 主要用于理解认证、服务端接口和关系数据库，不作为 Agent 核心；
- YOLO、SAM、自动标注是 Agent 调用真实工具的业务案例，不是最终学习目标；
- 本项目不接入 RAG 或向量数据库；LangGraph 和多 Agent 按实际学习问题展开，不提前堆叠技术；
- 新增学习文档一律使用中文文件名；
- 每个阶段达到验收标准后，再进入下一阶段。
