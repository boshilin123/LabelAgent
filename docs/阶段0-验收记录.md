```powershell
$sig = Get-ChildItem "<repo>\LR-Agent\vendor\local-agent\tests" -Recurse -File -Filter '*.py' |
       Sort-Object FullName | ForEach-Object { "$($_.Name):$($_.Length)" }
$digest = (SHA256([Text.Encoding]::UTF8.GetBytes($sig -join '|'))).Hex.Substring(0,16).ToUpper()
```

## 3. 旧路径行为基线（本阶段冻结的契约）

新增文件按计划 §5-阶段 0 的十类样例，每类固定四件事：**精确 `event.type` 序列**、承重帧**完整 `to_sse_dict()` 载荷**、注入假工具的**真实执行次数**、`tool_start`/`tool_pending`/`ToolMessage` 的 `tool_call_id` 对齐。

| # | 样例类 | 测试 | 钉住的关键事实 |

| 1 | 空工具调用 | `TestEmptyToolCall` | 纯文本轮 `preparing→text_delta`；零执行；`bind_tools` 仅 1 次（未触发 `tool_choice="any"` 兜底） |
| 2 | 单工具 | `TestSingleTool` | SYNC 工具轮 `tool_start→tool_result→text_delta`；执行 1 次；第二轮 ToolMessage id 对齐 |
| 3 | 多个工具 | `TestMultipleTools`(2) | 两并行只读工具保序、各 1 次；SYNC+ASYNC 同轮 → 先 SYNC 再 `tool_pending`（`clientToolCalls`+`toolCalls` 双写），**ASYNC 后端零执行** |
| 4 | 提案确认 | `TestProposalConfirm`(2) | pending→resume 的 ToolMessage 对齐与 `next_hint`；Keep All 后改写为 `proposal_pending=false / file_written=true`（谎报防护） |
