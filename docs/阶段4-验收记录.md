## 5. 规格更正（4b 实测，已回写规格与依赖文档）

1. **「suppressed 最前」在「合并 + 立即执行」共存轮不成立**：实测 `c2(coalesced) → r1(read) → c1(tool_pending)`（`_yield_blocked_call` 在合并循环里就地产出，存活者在 `async_pending`）。但 `phase_blocked` 型 suppressed 确实先于 execute_now。最终顺序 = **suppressed → execute_now → deferred**（deferred 使用合并后参数）。
2. **`langgraph_node == "tools"` 过滤挡不住 `after_model` 注入**：注入的 `client_tool_pending` 消息会被归因成 `node='tools'` 且同时出现在 `updates["tools"]["messages"]`。**权威判据只能是 `plan.deferred`**（已按父代理要求另加 `_is_after_model_node` 过滤并测试）。
3. **`ToolNode` 未注册工具文本与旧路径不同**（`Error: X is not a valid tool...` vs 旧 `未知工具: X`）：已在显示层按旧模板换回（`tool_loop.py:87-90`）。
4. **轮边界判据必须是「model 分片的 step 变化」**，不能把每个新 step 当新轮（after_model/tools 的消息属于本轮）。
